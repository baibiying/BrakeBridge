## 3. 明确不做（写了就是为了不让别人做）

| 不做 | 原因 | 谁最容易手痒 |
| --- | --- | --- |
| **PDF 重新抽取**（除非现有 CSV 抽检失败率 >10%） | CSV 已经抽好，重抽是纯体力活 | D1 |
| 全量目录 OCR（其余纯图页） | 每页一次版式博弈，7 小时做不完 | D1 |
| 尺寸 → 型号 全映射 | 型号印在图里，文字层没有；编造型号会毁可信度 | D1 / D2 |
| 车桥铭牌识别 | 需要桥型号词表 + 视觉模型 | D2 |
| 买家名单导入页 + 去重 | 本轮用预置样例展示，不做上传解析 | D3 |
| 证据卡 / 采购能力判断 / 跟进指派 / CSV 导出 | 全是 P1；做了也讲不完 | D3 / PM |
| Facebook Graph API / WhatsApp 接入 | 无权限、无时间 | 任何人 |
| LLM 生成候选或价格 | 防幻觉红线，写进代码 | D2 |
| 向量库 / 编辑距离模糊召回 | 153 条规模用字典足够；P1 再说 | D2 |
| 重构前端、换框架、上 Tailwind | 7 小时里框架切换 = 项目自杀 | D3 |
| 电话/邮件自动发送 | 演示不需要，风险高 | PM |
