### D1-02 三个数字怎么补

1. 先用 PyMuPDF 打开对应页，`page.get_text("blocks")` 拿 bbox；
2. 按 C1 里的列心 x（kooying ≈137/420/714/1004；冠隆 ≈35/300/630/895）切列；
3. 在你那条记录同一行的右侧区域找形如 `10 120 8` 的数字串，写进 `raw_nums`；
4. 按「孔数/孔距/片数」顺序拆进三列；
5. **找不到就留 `null`，不要猜、不要跨行借数字。** 猜出来的数字会在台上被一眼看穿。

## 4. 常见坑（别踩第二遍）

| 坑 | 现象 | 处理 |
| --- | --- | --- |
| 图注尺寸混入 | 一行里出现两套尺寸，A/B 串成一行 | 按 x 带排除列间数字（15.91 / 39.92 / 79.33 / 117.7 这类） |
| 全半角括号 | `(ABS)` 与 `（ABS）` 混用导致同名不合并 | 归一化时统一 |
| 异体字 | `⻛` `⻰` `⻁` `⻢` 不在常用字区 | 归一化表里显式替换 |
| 行号错位 | 删行后 `cell` 里的 r 与实际不符 | 重新按列顺序编号，不要在中间插行 |
| 空尺寸被当 0 | `l=0` 会污染过滤 | 空就 `null`，不写 0 |
