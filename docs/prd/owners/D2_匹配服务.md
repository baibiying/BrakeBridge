### D2-01 归一化顺序（照这个顺序，别调换）

```
1 繁简/异体统一：⻛→风、⻰→龙、⻁→虎、⻢→马
2 去空格、全角转半角
3 去 (ABS) / （ABS）
4 去尾部标记：前 / 后 / A / B / 改型（可叠加，如「杰狮C6前A」→「杰狮C6」）
5 别名映射：alias.json 命中 → 基础车型名
6 输出 base
```

**注意**：第 4 步去掉的标记要**保留**，作为 `position` / `variant` 的推断依据（例如请求里没给 `position`，但用户写的是「天锦KR前」，就该按“前”过滤）。

### D2-02 召回优先级

| 序 | 匹配方式 | `matched_by` | 行为 |
| --- | --- | --- | --- |
| a | `vehicle_norm` 精确命中 | `exact` | 取该车型全部 `status in (ok, 待核)` 条目 |
| b | 别名命中 | `alias` | 取目标车型条目 |
| c | 都失败 | `none` | `candidates: []`，`nearest` 给 3 个最相近的 `vehicle_norm`（用包含关系 + 长度差排序，不引第三方库） |

**`name_only` 条目永不进 `candidates`。**

### D2-03 置信度实现（照抄 C2，不许自创）

```python
def grade(matched_by, candidate_count, constraint_hits):
    if candidate_count == 0:
        return "无"
    if matched_by == "exact" and constraint_hits >= 1 and candidate_count <= 2:
        return "高"
    if matched_by == "exact" and candidate_count <= 4:
        return "中"
    return "低"
```

`assert_unique = (confidence == "高" and candidate_count == 1)`

## 5. 常见坑

| 坑 | 现象 | 处理 |
| --- | --- | --- |
| 别名冲突 | 同一别名挂两个车型 | 启动时检查，打印警告，取第一个 |
| 数字类型 | `width=155.0` 与 `w=155` 比较失败 | 统一 `int(round(float(x)))` |
| 空 `q` | 前端传空串 | 契约已定 400，不要返回 500 |
| 中文编码 | Windows 控制台打印乱码 | 测试时用 `python -X utf8`；文件读写显式 `encoding="utf-8"` |
| 每次请求重读 jsonl | 153 条不大，但演示时会明显卡 | 进程启动时加载一次进内存，`/api/match` 只查内存 |
