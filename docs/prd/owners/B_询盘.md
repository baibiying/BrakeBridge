| 编号 | 任务 | 完成判据 | 时间盒 |

| **B-01** | 粘贴与出卡 | 粘一条评论 → 卡片显示语言 / 车型 / 数量 / 原文 | 15:30–16:20 |

| **B-03** | 列表与筛选 | 全部 / 待回复 / 待复核 / 留档，带计数 | 17:00–17:40 |

| **B-07** | 交叉抽检 10 条 | 对 PDF 核速配数据，只报结论不改数据 | 20:30–21:00 |

### B-01 抽取规则

| 字段 | 规则 | 失败时 |
| --- | --- | --- |
| 语言 | 含中文字符 → 中文，否则英文 | 默认英文 |
| 车型 | 在 `data/fitment/alias.json` 里查别名（**只读**） | 显示「未识别车型」+ 手工输入框 |
| 数量 | 正则 `(\d+)\s*(sets?|pcs?|units?|套|件)` | 「未提及」 |
| 原文 | 原样保存 | — |

**不许调模型，不许自己编车型。**

### B-02 分类规则

- 三态：`待回复 / 待复核 / 留档`，由人点。
- 从一个态改到另一个态时，弹原因输入框，空原因不允许提交。
- 状态与原因都落盘。

### B-04 跳转细节

```python
# 车型命中
url = url_for("fitment.index", q=vehicle, from_="inquiry:" + inquiry_id)
```

字段名以 C 的实际实现为准，但 URL 形态必须是 `/fitment?q=...&from=inquiry:<id>`。

**车型为空时也允许跳**，让 C 走未收录态。

### B-07 交叉抽检怎么做

1. 打开 `data/fitment/fitment.jsonl`，挑 10 条 C 没抽过的（错开页码，优先冠隆 p17–19）。
2. 打开对应 PDF，核三件事：车型名、尺寸串、页码。
3. 只报「错几条 + 错在哪」，**不改数据**（改是 C 的活）。
4. 超过 2 条错，群里立刻说。
