### D3-01 骨架长什么样（照抄，别自创结构）

```
app.py                  # Flask 实例 + 注册 blueprint + 三个页面路由
api/__init__.py         # 你建空文件，D2 往里填
service/__init__.py     # 同上
scripts/__init__.py     # 同上
data/.gitkeep           # 同上
templates/base.html     # 你写
static/style.css        # 你写
requirements.txt        # flask>=3.0
README.md               # 三行：装依赖 / 启动 / 打开地址
```

`app.py` 里留好挂载点：

```python
from api.match import bp as match_bp
app.register_blueprint(match_bp, url_prefix="/api")
```

**如果 D2 的 `api/match.py` 还没就绪，用 `try/except ImportError` 兜住**，否则你推上去的骨架别人拉下来会直接崩，全组卡住。

### D3-02/03 页面与接口的对接方式

- 页面加载后**不自动查询**，点「查询」才发 `POST /api/match`；
- 从 `/inbox` 带 `q` 进来时，页面加载后自动查一次，顶部显示「来源评论 #id」；
- 所有候选字段**只读接口返回值**，前端不做任何尺寸推算；
- 置信度徽章三种颜色：高=绿、中=黄、低=灰；`assert_unique=true` 才显示「建议规格」四个字。

## 4. 常见坑

| 坑 | 现象 | 处理 |
| --- | --- | --- |
| 骨架上 main 太晚 | 两人干等 | 14:45 立即动手，占位页也算 |
| 骨架 import 崩 | 别人拉下来直接跑不起来 | 用 `try/except ImportError` 兜住 D2 的模块 |
| 前端自己算尺寸 | 与接口数据不一致 | 只渲染接口返回的 `size_raw` |
| 把“建议规格”写成“就是这款” | 违反防幻觉规则 | `assert_unique=true` 才出现这四个字 |
| 模板里硬编码页码 | 换一条数据就错 | 页码一律来自接口 |
| Windows 中文路径 | 模板加载失败 | 工作目录用英文路径，或统一相对路径 |
