## 3. 海报怎么排（照着排，不要现场想版式）

**A1 竖版 594×841mm**，导出 `poster_A1.pdf`（300dpi）+ `poster_1080x1920.png`。用 Canva 竖版海报模板，只换文字与图。

版面从上到下：

| 区块 | 占比 | 内容 |
| --- | --- | --- |
| 标题区 | 12% | 主标题 + 副标题（文案见 `demo/海报文案与简介.md`） |
| 痛点 | 12% | 一条询价过去 2 小时；翻两本册子；只有老销售会 |
| **主图** | **35%** | 三段链路图：评论 → 候选卡 → 报价草稿（用真实截图，不用示意图） |
| **数据证据** | **25%** | 153 条 / 145 条带尺寸 / 2 本真册 / 6 页 / 冲突自动标待核 |
| 团队 + 下一步 | 10% | 四人角色 + “要企业那张型号 Excel” |
| 页脚 | 6% | 项目名 + 二维码位置（**留空，不印体验链接**） |

**三条硬规矩**：
1. **80% 视觉重量给主图与数据证据**——两米外只看得见这两块。
2. 截图必须是**今晚真跑出来的**，不用示意稿；没跑到的那块就不上海报。
3. 文案里不许出现「全量 / 自动识别车桥 / 精准定价 / 100% 准确」。

## 4. 作品简介怎么写

四段，约 900 字，直接改 `demo/海报文案与简介.md` 里的成稿：

1. **问题**：海外询价只写车型俗称，销售要翻两本产品册、2 小时/条。
2. **做法**：把册子里已经排好的车型适配表变成可查数据（153 条 / 6 页 / 两本真册），候选带页码，缺信息就问，不替你断言。
3. **现场能看到什么**：粘贴一条评论 → 候选卡 → 一个追问 → 报价草稿（价格留空）。
4. **下一步**：询价日志自动扩表；企业给型号 Excel 后可补“尺寸→型号”断链。

**上传前检查**：字数符合平台限制、没有错别字、截图不超过平台允许数量、提交后截图存证。
