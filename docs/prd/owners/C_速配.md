### C-01 字段映射

| CSV | jsonl | 处理 |
| --- | --- | --- |
| `file` | `brand` / `src` | kooying→`KOOYING`；guanlong→`GUANLONG` |
| `page` `col` | `page` `cell` | `cell = c{col}r{该列出现序号}` |
| `vehicle` | `vehicle_raw` | 原文不动 |
| `vehicle` | `vehicle_norm` `position` `variant` | 去 `(ABS)`、拆尾部前/后/A/B、繁简统一 |
| `size` | `size_raw` `l` `w` `t1` `t2` | 按 `L×W×T1/T2` 拆，缺 `t2` 填 null |
| `oe` | `oe` | 空转 `[]` |
| — | `status` | 默认 `ok`，无尺寸 `name_only` |

`holes/pitch/pieces/raw_nums` 本轮可全 null（P1 再补）。**不知道就填 null，绝对不要猜。**

### C-03 匹配规则（照这个写）

```
归一化：异体字 → 去空格全半角 → 去 (ABS) → 去尾部前/后/A/B → 别名映射
召回：精确 → 该车型全部条目；别名 → 目标车型；失败 → candidates=[] + nearest 3 个
过滤：position / width / holes 任一命中即收缩
置信度：高=精确+≥1约束+候选≤2；中=精确+候选≤4；低=别名或>4；无=空
assert_unique = (高 and 候选==1)
```

### C-04 候选卡四行

```
1 规格：188×155×12.2/14 ｜ 孔数 10 ｜ 孔距 120 ｜ 片数 8
2 证据：kooying catalog.pdf p27 · 第 1 列第 6 行
3 置信度：高/中/低 + 一句话原因
4 待核项：第 3、4 个数字语义待企业确认（无则 —）
```

**只有 `assert_unique` 为真，才允许出现「建议规格」四个字。**
未命中态**不许出现任何尺寸数字**。
