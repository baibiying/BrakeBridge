## 2. 为什么这样能合并（三句话）

1. **三个人各占一个目录**，Git 合并时没有共同文件，不可能冲突。
2. **共享文件只有三份**（`app.py`、`base.html`、`base.css`），A 在 15:30 前写完即冻结，之后谁都不许改。
3. **跨功能只有一个 URL**：`/fitment?q=...&from=inquiry:<id>`，B 不需要 import C 的代码。

完整规则见 `contracts/C0_框架与合流契约.md`。

## 5. Gitee 协作

| 规则 | 内容 |
| --- | --- |
| 主干 | `master` 受保护，只接受 PR |
| 分支 | `feat/sourcing`（A）、`feat/inquiry`（B）、`feat/fitment`（C） |
| 顺序 | A 先推框架，其他人 `git pull` 后开分支 |
| PR | 三行：改了哪些文件 / 自测命令 / 自测输出一句。PM 30 秒合 |
| 冻结 | `app.py`、`templates/base.html`、`static/base.css`、`requirements.txt` 15:30 后不许改 |
| 不入库 | `__pycache__/`、`.venv/`、`*.pdf`、海报源文件 |
