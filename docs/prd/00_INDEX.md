## 5. Gitee 协作规则（已拍板：技能甲）

| 规则 | 具体要求 |
| --- | --- |
| 主干 | `main` 受保护，只接受 PR；内容只放**冻结物**：`docs/prd/` + 工程骨架 |
| 分支 | `feat/d1-data`、`feat/d2-match`、`feat/d3-ui`、`docs/pm-poster` |
| 顺序 | **D3 14:45–15:15 先把骨架推到 main**，其他人才 `git pull` 后开分支 |
| PR 模板 | 三行必写：① 改了哪些目录 ② 自测命令 ③ 自测输出一句 |
| 文档归属 | `docs/` **只有 PM 改**；开发分支里不许动 PRD，避免五份分叉 |
| 契约改动 | `contracts/` 两份只能 PM 提 PR 改；要改先在群里说，改完通知三人 |
| 数据产物 | `fitment.jsonl` / `alias.json` 由 D1 一人写，其他人只读 |
| 不入库 | `query_log.jsonl`、`__pycache__/`、`.venv/`、海报源文件（Canva/PPT） |
| 大文件 | 仓库只放最终 `poster_A1.pdf`；设计源文件放网盘，链接写进 `demo/` |
| 命名 | 提交信息：`d1: 补 holes/pitch/pieces`、`d2: /api/match 支持 width 过滤` |

**不搞 CI**：22 小时里没有时间修流水线。合并前由 PM 看 PR 三行，跑一次自测命令即可。
