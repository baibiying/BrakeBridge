## 2. 数据字段（照这个写，字段名不许改）

| 字段 | 类型 | 说明 |
| --- | --- | --- |
| `id` | string | `KL-p27-c1-r6`，全库唯一 |
| `brand` | string | `KOOYING` / `GUANLONG` |
| `src` | string | `kooying catalog.pdf` / `冠隆产品册.pdf` |
| `page` | int | 从 1 起 |
| `cell` | string | `c1r6` |
| `vehicle_raw` | string | 原文，保留 `(ABS)` `前A` |
| `vehicle_norm` | string/null | 去 ABS、去尾部前/后/A/B、繁简统一 |
| `position` | string/null | `前`/`后`/null |
| `variant` | string/null | `A`/`B`/null |
| `size_raw` | string/null | 原串，`×` 不换 `x` |
| `l` `w` `t1` `t2` | number/null | 按 `L×W×T1/T2` 拆；无 `t2` 填 null |
| `holes` `pitch` `pieces` | int/null | 本轮可全 null，**不许猜** |
| `oe` | array | 无则 `[]` |
| `status` | string | `ok` / `待核` / `name_only` |
| `confidence` | number | 有尺寸 0.95，仅车型名 0.5 |

`alias.json`：30 条，键是 `vehicle_norm`，值是别名数组，必须覆盖 天锦KR / 杰狮C6 / 汉德桥35T。

## 3. 匹配规则

```
归一化：异体字(⻛→风 ⻰→龙 ⻁→虎 ⻢→马) → 去空格全半角 → 去 (ABS)
        → 去尾部 前/后/A/B/改型 → 别名映射
召回：精确命中 vehicle_norm → 取该车型全部条目
      别名命中 → 取目标车型条目
      失败 → candidates=[] + nearest 3 个车型名
过滤：position / width / holes，任一命中即收缩
置信度：高=精确+≥1约束+候选≤2；中=精确+候选≤4；低=别名或>4；无=空
assert_unique = (高 and 候选==1)
```

**候选卡四行，顺序不许变**

```
1 规格：188×155×12.2/14 ｜ 孔数 10 ｜ 孔距 120 ｜ 片数 8
2 证据：kooying catalog.pdf p27 · 第 1 列第 6 行
3 置信度：高/中/低 + 一句话原因
4 待核项：第 3、4 个数字语义待企业确认（无则 —）
```

**未命中态**：大字「未收录」+ 最相近 3 个 + 3 条追问 + 手工输入框，**不出现任何尺寸数字**。
**来源显示**：URL 带 `from=inquiry:<id>` 时顶部显示「来源评论 #id」。
**手机**：`?mode=mobile` 隐藏导航与装饰，单列，字号放大。

**报价草稿**：规格核对 / 文件名+页码+单元格 / 材质「待企业确认」/ 报告 `TR-2024-XXXX（占位）` / **单价总价留空**。

## 5. 防幻觉（写进代码，不是写进文档）

1. 候选只能来自 `fitment.jsonl`，**没有任何模型生成路径**。
2. 未命中不许推测最可能的一款，`nearest` 只是提示。
3. 指不回页码的候选不展示。
4. 价格恒为空。
5. `assert_unique=false` 时页面不许出现「建议规格」「就是这款」。
