## 0. 这块要解决什么

**用户**：冠英外贸销售与技术核价（现场汽配店 / 展会 / 询盘回复）。

### 0.0 领域公理（写进产品，不可改）

> **一条具体车桥 ↔ 一片刹车片，关系固定（1:1）。**  
> 这里的「具体车桥」= 车桥型号 + 安装位置（前/后）；若目录区分 A/B 版本，则 A、B 视为两条不同车桥，各对应一片。

推论：

- **已知具体车桥** → 必须能唯一给出片（或明确未收录）。  
- **只知车型** → 因后市场可换桥，一车型可能挂多条车桥 → **禁止**唯一断言，只能列出「可能车桥/适配」并追问车桥。  
- **无主机厂 OE** → 不定型靠 OE；定型靠车桥（或能映射到车桥/尺寸的现有编码）。

### 0.0b 现状（必须覆盖）

| 现状 | 含义 | 速配怎么接 |
| --- | --- | --- |
| **型号对不上** | 装片看**车桥**；无主机厂 OE 直通 | 匹配主线=车桥；OE 不做；编码仅作跨码到目录尺寸/车桥 |
| **换车桥后车型锁不住** | 车型 ≠ 唯一车桥 | 车型入口只出「可能车桥列表」+ 追问；**不**报唯一片 |
| **编码体系乱** | 同品在不同主机厂码不同；**同一车企**渠道/工厂也可能多码 | 一物多码表：多码 → 同一 `master_id` / 车桥尺寸 |
| **报价慢** | 对材质+型号约 2h/条 | 车桥定型后秒出规格 + **报价依据**；价空 |

### 0.0e 一物多码（必须覆盖）

> **痛点原话**：同一款产品在不同主机厂的编码不一样，甚至在同一家车企里也会出现不同编码。

**产品定义**

- **一物** = 冠英主件号 `master_id` = 一条具体车桥适配尺寸（与公理 1:1 对齐）  
- **多码** = 任意外部编码（主机厂侧码、桥厂工厂码、后市场/竞品码、尺寸串、内部对照码）  
- **规则**：多码只是入口别名，**不得**拆成多片；任一码命中 → 同一 `master_id` + 同一目录证据

**解决方案（数据 + 匹配）**

```text
客户报的任意码
    │
    ▼
parts_master.code_map[] / alt_codes[]   ← 跨厂 + 同企多码登记
    │
    ▼
master_id ──1:1──► size_raw / axle_key ──► 目录页证据 + 价区 + 为什么
    │
    └── 卡片展示「同片还可对照」兄弟码（让销售解释为何客户码和目录码不一样）
```

兜底：`crosswalk.json` 仍可把码映射到尺寸/条目；**优先** `parts_master`。  
**不做**：主机厂 OE 全库直连、自动爬码；本轮用校对过的示意表演示闭环。

**验收口径**

| 客户报的码 | 预期 |
| --- | --- |
| `DF-PAD-188A`（东风渠道 A） | → `PAD-TJ-KR-FA` |
| `DF-PAD-188B`（东风渠道 B，同企不同码） | → **同一** `PAD-TJ-KR-FA` |
| `OEM-FAW-188-12`（另一主机厂示意） | → **同一** `PAD-TJ-KR-FA` |
| `WVA-TJ-KR-FA`（后市场） | → **同一** `PAD-TJ-KR-FA` |
| `HANDE-F-240220` 与 `OEM-SX-35T-F` | → **同一** `PAD-HD35T-F` |

### 0.0c 赛题对齐

> **让一线销售当场能答**：客户说出**车型、车桥或现有编码**时，能快速给出对应的刹车片规格和**报价依据**。

海报验收口径（路演金句）：客户报**车型 + 车桥型号**时，**30 秒内**给出 **2–3 个候选件号 + 价格区间**，并讲清**为什么是这几个**。

| 客户说 | 入口 | 系统行为 |
| --- | --- | --- |
| 只报车型 | `q` | **先问车桥**（五问卡）；可列出可能车桥，禁止唯一件号 |
| 车型+车桥 / 只报车桥 | `q`+`axle` / `axle` | 车桥优先匹配 → **2–3 候选**（含前/后或材质档）+ 价区 + 依据 |
| 现有编码 | `code` | 一物多码表命中 → 候选 + 依据 |
| 定型勾选 | 草稿 | 报价依据清单；成交价仍人工 |

**不在范围**：主机厂 OE 库直连、铭牌 OCR 自动识别、真实进销存锁价。

### 0.0d 海报三步法（产品主叙事）

```text
痛点：客户报车型，我们答不上件号
      （要对的是车桥；后市场常换桥；一物多码）

① 先问车桥，不问车型
   把「这车用哪个片」拆成：
   车桥型号 / 年份 / 鼓或盘 / 吨位 / 参考照片（本轮照片可占位）

② 查得到，对得上
   产品目录 + 试验报告 → 一物多码表
   原厂/竞品码 ↔ 车桥型号 ↔ 冠英主件号

③ 当场给出答案
   2–3 个候选件号 + 价格区间 + 「为什么是这几个」（目录页/历史询价/车桥 1:1）
```

**高分信号（评审听得懂）**

1. 车桥优先匹配（数字化「车桥总图」= 目录 `axle_key`）  
2. 型号↔编码对照（一物多码，`parts_master` + `crosswalk`）  
3. 对照历史询价（示意字段 `history_note`）

## 2.5 速配逻辑说明（给评审 / 队友看）

> 一句话：**先问车桥 → 一物多码对得上 → 30 秒内 2–3 候选 + 价区 + 为什么。** 车型只指路；具体车桥 1:1 定片。

### 核心模型

```text
线索/客户
   │
车型 ──1:N──► 可能车桥 ──1:1──► 主件号(master_id)
                                    │
                                    ├── 一物多码 alt_codes[]
                                    ├── 目录尺寸 + 页码证据
                                    ├── 材质档 / 试验报告
                                    └── 示意价区 + 历史询价注记
```

- `axle_key` = `vehicle_norm` + `position` + `variant`  
- `parts_master`：主件号 ↔ 尺寸 ↔ 多码 ↔ 价区  

### 端到端（对齐海报三步）

```text
① 先问车桥：表单收 车桥型号 / 年份 / 鼓|盘 / 吨位 /（照片占位）
   若只填车型 → 五问提示 + 可能车桥列表，不出唯一件号

② 查得到对得上：目录 jsonl + crosswalk + parts_master
   车桥优先召回；编码走一物多码；过滤鼓盘/位置等

③ 当场答案：Top 2–3 候选卡
   件号 · 多码 · 价区 · 目录证据 · 为什么（车桥1:1 / 历史询价）
   勾选 → 报价依据草稿（成交单价仍空，价区仅示意）
```

### 演示路径

| 场景 | 操作 | 预期 |
| --- | --- | --- |
| 海报金句 | 车型天锦KR + 车桥相关消歧 | ≤3 候选，含件号/价区/为什么 |
| 车桥 | 汉德桥35T | 前+后 共 2 候选；+前 → 1 条定型 |
| 编码 | WVA-TJ-KR-FA | 一物多码命中主件号 + 依据 |
| 同企多码 | DF-PAD-188A / DF-PAD-188B | 均 → `PAD-TJ-KR-FA`，卡片列出兄弟码 |
| 跨厂多码 | OEM-FAW-188-12 与 WVA | 均 → 同一主件号 |
| 只车型 | 天锦KR | 先问车桥；列出可能桥，无唯一断言 |

### 报价依据

候选卡上写清「为什么」；草稿汇总：具体车桥、规格、目录页、多码、材质/报告、价区示意、成交价留空。

## 3. 匹配规则（实现核对用）

```
公理：axle_key(=vehicle_norm+position+variant) 1:1 对应一片（去重后）
入口优先级：code > axle > q（车型）
编码召回：parts_master（alt_codes + code_map）→ crosswalk → 条目 id → oe[] → 尺寸串
  · 同企多码 / 跨厂多码 一律落到同一 master_id（禁止因码不同拆片）
  · 命中后在 why 中带出兄弟码，便于口头解释
车桥召回：关键字命中；未选前/后则返回多条（各为独立 1:1）；选了位置则应唯一
车型召回：只作「可能车桥」列表 + 追问；默认 assert_unique=false
五问辅字段：year / brake_type / tonnage（软过滤；照片占位）
过滤：position / variant / w / l / holes / brake_type 用于消歧
展示上限：车桥/编码 Top≤3；车型-only ≤4（验收）
assert_unique = 去重后候选==1 且 code/axle 已定位或车型已消歧
置信度：唯一车桥→高；多车桥待确认→中/低；空→无
```

**候选卡（海报当场答案）**

```
1 件号：PAD-…（master_id）
2 多码：按来源列出（东风渠道A/B · 一汽示意 · 后市场 · 尺寸串…）
3 规格：188×155×12.2/14
4 价区：USD 12–18（示意，非锁价）
5 证据：kooying catalog.pdf p27 · 第 1 列第 6 行
6 为什么：车桥1:1 + 目录页 + 一物多码同片 + 历史询价
7 待核项：…
```

**未命中态**：大字「未收录」+ 最相近 3 个 + 五问追问，**不出现任何尺寸数字**。
**来源显示**：URL 带 `from=inquiry:<id>` 时顶部显示「来源评论 #id」。
**手机**：`?mode=mobile` 隐藏导航与装饰，单列，字号放大。

**报价草稿（报价依据）**：具体车桥 / 主件号 / 一物多码 / 规格 / 目录证据 / 为什么 / 材质·报告 / 价区示意 / 认证待确认 / **成交单价总价留空**。
