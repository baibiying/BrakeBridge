## 2. `data/fitment/fitment.jsonl`（C）

一行一条，UTF-8，无 BOM。

| 字段 | 类型 | 必填 | 说明 |
| --- | --- | --- | --- |
| `id` | string | ✅ | `KL-p27-c1-r6`，全库唯一 |
| `brand` | string | ✅ | `KOOYING` / `GUANLONG` |
| `src` | string | ✅ | `kooying catalog.pdf` / `冠隆产品册.pdf` |
| `page` | int | ✅ | 从 1 起 |
| `cell` | string | ✅ | `c1r6` |
| `vehicle_raw` | string | ✅ | 原文，保留 `(ABS)` 与 `前A` |
| `vehicle_norm` | string|null | ⚠️ | 归一化基础车型名；`name_only` 可为 null |
| `position` | string|null | ⚠️ | `前`/`后`/null（原文没写就 null） |
| `variant` | string|null | ⚠️ | `A`/`B`/null |
| `size_raw` | string|null | ⚠️ | 原串，`×` 不换 `x` |
| `l` `w` `t1` `t2` | number|null | ⚠️ | mm；无 `t2` 填 null |
| `holes` `pitch` `pieces` | int|null | ⚠️ | 语义待确认，本轮可全 null |
| `raw_nums` | string|null | ⚠️ | 三个数字原串 |
| `oe` | array | ✅ | 无则 `[]` |
| `status` | string | ✅ | `ok` / `待核` / `name_only` |
| `confidence` | number | ✅ | 有尺寸 0.95，仅车型名 0.5 |

**状态规则**：`ok` 正常展示；`待核` 展示但标角标；`name_only` 不进候选，只进“最相近车型”提示。

## 3. `data/fitment/alias.json`（C 产出，B 只读）

```json
{
  "东风天锦KR": ["天锦", "天锦KR", "东风天锦", "EQ天锦"],
  "红岩杰狮":   ["杰狮", "杰狮C6", "上汽红岩"],
  "解放虎威":   ["虎威", "小虎威", "解放虎V"]
}
```

- 键是 `vehicle_norm`，值是别名数组。
- 30~50 条，必须覆盖天锦KR、杰狮C6、汉德桥35T。
- 同一别名不许挂两个键，冲突时取第一个并打警告。
- **B 只读，不许写这个文件。**

## 4. `data/sourcing/buyers.json`（A）

```json
[
  {
    "id": "b1",
    "name": "Ravi Auto Parts",
    "country": "India",
    "category": "brake lining",
    "has_china_purchase": "有",
    "can_buy": "有迹象",
    "expo_intent": "未提及",
    "evidence": "We import brake parts from China",
    "dedupe_key": "ravi autoparts|india"
  }
]
```

- `dedupe_key`：`name` 去空格转小写 + `|` + `country`，用于判重。
- 三个判断字段只允许：`有 / 有迹象 / 未提及 / 待核`。
- `evidence` 必须是原文一句，不能改写。

## 5. `data/inquiry/inquiries.json`（B）

```json
[
  {
    "id": "inq-1",
    "text": "Please quote 217 sets of T850 front brake linings.",
    "lang": "en",
    "vehicle": "",
    "qty": 217,
    "status": "待回复",
    "reason": "",
    "created": "2026-11-21T16:10:00+08:00"
  }
]
```

- `status` 三选一：`待回复 / 待复核 / 留档`。
- 改判时 `reason` 必填。
- 每次改动即时写盘，刷新后仍在。

---

## 6. 通用规则

| 规则 | 内容 |
| --- | --- |
| 编码 | 全部 UTF-8，读写显式指定 `encoding="utf-8"` |
| 写盘 | 先写临时文件再替换，或 `json.dump(..., ensure_ascii=False, indent=2)` |
| 字段名 | 不许改。要加字段，先改本文件并发群里 |
| 时间 | ISO 8601 带时区，如 `2026-11-21T16:10:00+08:00` |
| 空值 | 一律 `null` 或 `""`，**不许写 0 代替空**（0 会污染过滤） |
