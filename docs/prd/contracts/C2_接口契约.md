## 3. `POST /api/match`

### 3.1 请求

```json
{
  "q": "天锦KR",
  "position": "前",
  "width": 155,
  "holes": null,
  "from": "comment:3"
}
```

| 字段 | 类型 | 必填 | 说明 |
| --- | --- | --- | --- |
| `q` | string | ✅ | 车型/车桥/编码，1~40 字；去首尾空格后为空 → `400` |
| `position` | string | ❌ | `前` / `后` / 不传 |
| `width` | int | ❌ | mm，不传即不过滤 |
| `holes` | int | ❌ | 不传即不过滤 |
| `from` | string | ❌ | 来源标记，仅用于日志与页面显示，不参与匹配 |

### 3.2 成功响应（`200`）

```json
{
  "ok": true,
  "q": "天锦KR",
  "base": "东风天锦KR",
  "matched_by": "alias",
  "confidence": "中",
  "assert_unique": false,
  "candidates": [
    {
      "id": "KL-p27-c1-r6",
      "size_raw": "188×155×12.2/14",
      "l": 188, "w": 155, "t1": 12.2, "t2": 14,
      "holes": 10, "pitch": 120, "pieces": 8,
      "position": "前", "variant": "A",
      "src": "kooying catalog.pdf", "page": 27, "cell": "c1r6",
      "status": "ok",
      "verify_note": "第 3、4 个数字语义待企业确认"
    }
  ],
  "need_ask": ["是前桥还是后桥？", "原车片宽是多少（mm）？"],
  "nearest": [],
  "evidence": [
    {"id": "KL-p27-c1-r6", "src": "kooying catalog.pdf", "page": 27, "vehicle_raw": "东风天锦KR前A（ABS）"}
  ]
}
```

### 3.3 未命中响应（`200`，不是 404）

```json
{
  "ok": true,
  "q": "不存在的车型XYZ",
  "base": null,
  "matched_by": "none",
  "confidence": "无",
  "assert_unique": false,
  "candidates": [],
  "need_ask": ["是前桥还是后桥？", "原车片宽是多少（mm）？", "是 A 版还是 B 版？"],
  "nearest": ["东风天锦KR", "东风多利卡", "解放虎威"],
  "evidence": []
}
```

**未命中时不许返回任何 `size_raw` 或型号。**

### 3.4 错误

| 码 | 条件 | 响应体 |
| --- | --- | --- |
| `400` | `q` 空 / 超 40 字 / `width` 非数字 | `{"ok": false, "error": "invalid_q"}` |
| `500` | 内部异常 | `{"ok": false, "error": "internal", "hint": "<一句日志摘要>"}` |

D3 必须能处理 `ok:false`：页面显示「服务异常，请重试」，不白屏。

## 4. 置信度规则（D2 实现，D3 只展示）

| 等级 | 条件（从高到低匹配，命中即止） |
| --- | --- |
| **高** | 车型精确命中（`matched_by=exact`）且 至少 1 个约束命中（position/width/holes）且 候选 ≤2 |
| **中** | 车型精确命中，但无约束命中或候选 3~4 |
| **低** | 别名/模糊命中（`matched_by=alias/nearest`），或候选 >4 |
| **无** | 候选为空 |

**`assert_unique = true` 的唯一条件**：`confidence == "高"` 且 `len(candidates) == 1`。其他一律 `false`。

---

## 5. `need_ask` 生成规则（最多 3 条，按顺序取）

1. 候选里同时存在前/后，且请求未给 `position` → 「是前桥还是后桥？」
2. 候选里存在 A/B 变体，且未给 `variant` → 「是 A 版还是 B 版？」
3. 候选宽度不一致，且未给 `width` → 「原车片宽是多少（mm）？」
4. 候选孔数不一致，且未给 `holes` → 「原车几孔？」
5. 仍未命中 → 「有没有旧编码或 OE 号？」

话术中文在前、英文在后，英文版由 D3 静态模板拼接（不调模型）。

## 6. `POST /api/quote`

### 6.1 请求

```json
{"ids": ["KL-p27-c1-r6", "KL-p28-c3-r7"], "customer": "Ravi Auto Parts"}
```

### 6.2 响应

```json
{
  "ok": true,
  "lines": [
    {
      "id": "KL-p27-c1-r6",
      "spec": "188×155×12.2/14",
      "holes": 10, "pitch": 120, "pieces": 8,
      "source": "kooying catalog.pdf p27 · c1r6",
      "status": "ok",
      "report_no": "TR-2024-XXXX（占位）",
      "material": "待企业确认",
      "unit_price": null,
      "qty": null,
      "amount": null
    }
  ],
  "note": "价格与材质需企业确认后回填"
}
```

**硬规则**：`unit_price` / `amount` 恒为 `null`；`report_no` 必须是明显占位（含 `XXXX`），不许编真实编号。

## 7. 埋点（`query_log.jsonl`）

每次 `/api/match` 调用（含 400）落一行：

```json
{"ts":"2026-11-21T15:42:10+08:00","q":"天锦KR","position":"前","width":155,
 "hit":true,"candidates":4,"asserted":false,"confidence":"中","matched_by":"exact","from":"web"}
```

| 字段 | 说明 |
| --- | --- |
| `ts` | ISO 8601 带时区 |
| `hit` | 候选数 > 0 |
| `asserted` | 本次是否 `assert_unique=true` |
| `from` | 请求里的 `from`，无则 `web` |

写日志失败**不许中断请求**（try/except 后打一行 stderr，日志丢一条不影响演示）。
