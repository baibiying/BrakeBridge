## 3. 关键规则

| 字段 | 规则 |
| --- | --- |
| 语言 | 含中文 → 中文，否则英文 |
| 车型 | 查 `data/fitment/alias.json`（只读），找不到显示「未识别车型」+ 手工输入 |
| 数量 | 正则 `(\d+)\s*(sets?|pcs?|units?|套|件)` |
| 分类 | 三态 `待回复 / 待复核 / 留档`，**由人点，不做自动分类** |
| 改判 | `reason` 必填，与状态一起落盘 |
| 原文 | 原样保存 |

**不许调模型，不许自己编车型。**

## 4. 边界

只碰 `features/inquiry/` 和 `data/inquiry/`。`data/fitment/alias.json` 只读。冻结文件不碰。

## 5. 抽检怎么做（B-07）

1. 打开 `data/fitment/fitment.jsonl`，挑 10 条 C 没抽过的。
2. 对照 PDF 核：车型名、尺寸串、页码。
3. 只报「错几条 + 错在哪」，不改数据。
4. 超过 2 条错，群里立刻说。
