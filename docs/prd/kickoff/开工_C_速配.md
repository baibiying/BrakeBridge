## 3. 数据转换要点

| CSV | jsonl | 处理 |
| --- | --- | --- |
| `file` | `brand` `src` | kooying→`KOOYING` |
| `page` `col` | `page` `cell` | `c{col}r{序号}` |
| `vehicle` | `vehicle_raw` | 原文不动 |
| `vehicle` | `vehicle_norm` `position` `variant` | 去 ABS、拆前/后/A/B、繁简统一 |
| `size` | `size_raw` `l` `w` `t1` `t2` | 按 `L×W×T1/T2` 拆 |
| — | `holes` `pitch` `pieces` | 本轮可全 null，**不许猜** |

---

## 4. 匹配规则

```
归一化 → 精确/别名召回 → 前/后、宽度、孔数过滤 → 置信度
高 = 精确 + ≥1 约束 + 候选 ≤2
中 = 精确 + 候选 ≤4
低 = 别名命中或候选 >4
assert_unique 只在 高+候选=1 时为真
```

**候选卡四行**：规格 / 证据（文件+页码+单元格）/ 置信度 / 待核项。
**只有 assert_unique 为真才显示「建议规格」。未命中态不许出现任何尺寸。**
