## 4. 数据契约要点（照这个写，字段名不许改）

| 字段 | 类型 | 说明 |
| --- | --- | --- |
| `id` | string | `KL-p27-c1-r6` 这种格式，全库唯一 |
| `brand` | string | `KOOYING` / `GUANLONG` |
| `src` | string | `kooying catalog.pdf` / `冠隆产品册.pdf` |
| `page` `cell` | int / string | 页码从 1 起；`cell` 形如 `c1r6` |
| `vehicle_raw` | string | 原文，保留 `(ABS)` `前A` |
| `vehicle_norm` | string | 去 ABS、去尾部前/后/A/B、繁简统一 |
| `position` `variant` | string/null | 从原文尾部拆，没有就 `null` |
| `size_raw` | string | 原串，`×` 不要换成 `x` |
| `l` `w` `t1` `t2` | number | 按 `L×W×T1/T2` 拆，缺 `t2` 填 `null` |
| `holes` `pitch` `pieces` | int/null | 语义待企业确认，不确定填 `null` |
| `raw_nums` | string | 三个数字原串，如 `"10 120 8"` |
| `oe` | array | 空就 `[]` |
| `status` | string | `ok` / `待核` / `name_only` |
| `confidence` | number | 有尺寸 0.95，只有车型名 0.5 |

**三个数字的硬规定**：不知道就填 `null`，**绝对不要猜**。猜出来的数字会在台上被一眼看穿。
