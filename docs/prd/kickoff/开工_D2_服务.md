## 4. 归一化顺序（不许调换）

```
1 异体字统一：⻛→风、⻰→龙、⻁→虎、⻢→马
2 去空格、全角转半角
3 去 (ABS) / （ABS）
4 去尾部标记 前/后/A/B/改型（可叠加）
5 别名映射 → 基础车型名
```

第 4 步去掉的标记要存下来，作为 `position` / `variant` 的推断依据。

## 5. 接口契约（照这个返回，字段名不许改）

**请求**

```json
{"q": "天锦KR", "position": "前", "width": 155, "holes": null, "from": "comment:3"}
```

**成功响应**

```json
{
  "ok": true, "q": "天锦KR", "base": "东风天锦KR",
  "matched_by": "exact", "confidence": "中", "assert_unique": false,
  "candidates": [{"id":"KL-p27-c1-r6","size_raw":"188×155×12.2/14",
    "l":188,"w":155,"t1":12.2,"t2":14,"holes":10,"pitch":120,"pieces":8,
    "position":"前","variant":"A","src":"kooying catalog.pdf","page":27,
    "cell":"c1r6","status":"ok","verify_note":"第 3、4 个数字语义待企业确认"}],
  "need_ask": ["是前桥还是后桥？"],
  "nearest": [],
  "evidence": [{"id":"KL-p27-c1-r6","src":"kooying catalog.pdf","page":27}]
}
```

**未命中**：`candidates: []`，`matched_by: "none"`，给 `need_ask` 3 条与 `nearest` 3 个车型名。**不许返回任何尺寸或型号。**

**错误**：`q` 空或超 40 字回 400 `{"ok":false,"error":"invalid_q"}`；内部异常回 500。

**置信度**

| 等级 | 条件 |
| --- | --- |
| 高 | 精确命中 + 至少 1 个约束命中 + 候选 ≤2 |
| 中 | 精确命中，缺约束或候选 3~4 |
| 低 | 别名/模糊命中，或候选 >4 |
| 无 | 候选为空 |

**`assert_unique` 只在「高 + 候选=1」时为真，其他一律假。**
