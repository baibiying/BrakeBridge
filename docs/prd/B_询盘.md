## 1. 你的目录与边界

```
features/inquiry/            ← 你独占

  templates/inquiry/*.html
data/inquiry/inquiries.json  ← 你独占

```

技术栈：Python 3.12 + Flask 3 + Jinja2 + JSON 文件，端口 5000。
`app.py`、`templates/base.html`、`static/base.css`、`requirements.txt` 由 A 在 15:30 前写完并冻结，**你不改**。
导航已有三条链接：`/sourcing` `/inquiry` `/fitment`。

**跨功能只有一个链接**（你只需要生成它）：

```
/fitment?q=<车型文本>&from=inquiry:<id>
```

`q` 车型识别失败就传空串，C 那边会进入未收录态。`from` 只用于速配页顶部显示来源。

## 3. 规则（写死）

| 字段 | 规则 | 失败时 |
| --- | --- | --- |
| 语言 | 含中文字符 → 中文，否则英文 | 默认英文 |
| 车型 | 查 `data/fitment/alias.json` 的别名 | 显示「未识别车型」+ 手工输入框 |
| 数量 | 正则 `(\d+)\s*(sets?|pcs?|units?|套|件)` | 未提及 |
| 原文 | 原样保存 | — |

**分类永远由人点**：`待回复 / 待复核 / 留档`。改判要填原因，原因与状态一起落盘。
**不许调模型，不许自动分类，不许自己编车型。**

数据文件格式：

```json
[{"id":"inq-1","text":"...","lang":"en","vehicle":"","qty":217,
  "status":"待回复","reason":"","created":"2026-11-21T16:10:00+08:00"}]
```

导出列：`id,created,lang,vehicle,qty,status,reason,text`，文件名 `inquiries_<yyyymmdd>.csv`。
