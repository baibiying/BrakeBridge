# F1 · 拓客（本轮不做，只保留叙事）

> **结论先行：本轮 0 人天投入。** 海报与路演里只用两句话带过，不加任何页面。
> 写这份文档是为了防止有人问“拓客呢”，以及说清 P1 真正要做时的工作量。

---

## 1. 这一块解决什么问题

海外买家（经销 / 修理厂 / 车队）在 Facebook 上看到产品、发评论或私信。销售要先判断：
**这个买家值不值得回、凭什么回、用什么话回。**

理想形态三件套：

1. **买家名单**：CSV/Excel 导入 → 去重 → 新增 / 重复 / 跳过的回显
2. **证据卡**：品类、采购能力、是否有中国采购经历、展会意向，每条结论挂原文出处
3. **英文邀约**：按品类 + 补问行程 / 公司 / 数量；展位信息缺失时自动省略，改问行程

## 2. 本轮为什么不做

## 3. 本轮只做的一件事：叙事承接

海报与路演里，F1 用下面两句话占位：

> 「一条 Facebook 询价评论，过去要人工翻册子两小时；现在粘贴进来，系统告诉你该问什么、能报什么规格。」

即：**不展开展示拓客页面，只用它作为“输入”的一侧，把观众引到 F2 的评论入口。**
