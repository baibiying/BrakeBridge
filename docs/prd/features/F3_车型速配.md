> 目标：**客户说一句车型俗称，从 153 条真实适配记录里召回 1~4 个候选，每张卡都能点回册子页码，问一个问题收敛，最后出一张价格留空的报价草稿。**
> 目录：`features/fitment/`，数据：`data/fitment/`

---

```

```

## 3. 匹配规则

**归一化顺序**：异体字（⻛→风、⻰→龙、⻁→虎、⻢→马）→ 去空格全半角 → 去 (ABS) → 去尾部前/后/A/B/改型 → 别名映射。

**召回**：精确命中 `vehicle_norm` → 取全部条目；别名命中 → 取目标车型条目；失败 → `candidates: []` + `nearest` 3 个车型名。

**过滤**：`position`（前/后）、`width`、`holes`，任一命中即收缩。

**置信度**

| 等级 | 条件 |
| --- | --- |
| 高 | 精确命中 + 至少 1 个约束命中 + 候选 ≤2 |
| 中 | 精确命中，缺约束或候选 3~4 |
| 低 | 别名命中，或候选 >4 |
| 无 | 候选为空 |

**`assert_unique` 只在「高 + 候选=1」时为真。**

---

## 4. 页面（`/fitment`）

**顶部**：车型文本框 + 前/后下拉 + 宽度 + 孔数 + 查询按钮。

**候选卡四行，顺序不许变**：

```
1 规格：188×155×12.2/14 ｜ 孔数 10 ｜ 孔距 120 ｜ 片数 8
2 证据：kooying catalog.pdf p27 · 第 1 列第 6 行
3 置信度：高/中/低 + 一句话原因
4 待核项：第 3、4 个数字语义待企业确认（无则 —）
```

**底部**：`生成报价草稿`（勾选后可用）、`复制追问话术`（中英各一段）。

**未命中态**：大字「未收录」+ 最相近 3 个 + 3 条追问 + 手工输入框。**不出现任何尺寸数字。**

**来源显示**：URL 带 `from=inquiry:<id>` 时，顶部显示「来源评论 #id」。

**手机**：`?mode=mobile` 隐藏导航与装饰，单列，字号放大。

---

## 6. 防幻觉硬规则

1. 候选只能来自 `fitment.jsonl`，**没有任何模型生成路径**。
2. 未命中不许“推测最可能的一款”，`nearest` 只是提示。
3. 指不回页码的候选不展示。
4. 价格恒为空。
5. `assert_unique=false` 时，页面不许出现「建议规格」「就是这款」。

## 9. 边界

- 只支持中文俗称，不做英文车型名。
- 单位统一 mm，不做英寸换算。
- 型号（GYS/GY）不承诺，因为文字层没有。
- 车桥只有“桥厂 + 吨位”，换桥场景只做追问。
