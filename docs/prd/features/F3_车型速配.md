# F3 · 车型速配（本轮主战场）

> **一句话**：客户说“我这台天锦KR用什么片”，系统从 153 条真实适配表里召回 1~4 个候选，每个候选都带册子页码，追问一个问题收敛，最后出一张可审的报价草稿——价格留空。

---

## 1. 要解决的真实问题

海外买家发来的询价只写车型俗称：「天锦KR」「杰狮」「6700」「新98R」。
销售要做的活是：**翻两本产品册，找到对应规格，判断前桥还是后桥、A 版还是 B 版，再决定该问什么。**

这段活在现实里是 2 小时/条，而且只有老销售会做。所以本功能不是“搜索框”，是**把老师傅的判断拆成可审判的步骤**。

---

## 2. 端到端链路

```
① 输入车型（或从 /inbox 带入）
        ↓
② 归一化：繁简/异体 → 去空格全半角 → 去 (ABS) → 去尾部 前/后/A/B → 别名映射 → 基础车型名
        ↓
③ 召回：精确命中 → 该车型全部条目；别名命中 → 目标车型条目；全失败 → not_found + 最相近 3 个
        ↓
④ 过滤：position(前/后) / variant(A/B) / width / holes，任一命中即收缩
        ↓
⑤ 置信度：高 / 中 / 低（规则见 C2）
        ↓
⑥ 输出：候选卡（尺寸 / 孔数·孔距·片数 / 页码 / 来源册 / 状态）
        + need_ask（缺什么问什么，最多 3 条）
        + assert_unique（只有“高 + 单一候选”才允许为 true）
        ↓
⑦ 勾选候选 → 报价草稿（规格核对 + 页码依据 + 报告编号占位 + 价格留空）
```

## 3. 页面要素（`/match`）

### 3.1 顶部输入区

| 控件 | 类型 | 说明 |
| --- | --- | --- |
| 车型/车桥/编码 | 文本框 | 唯一必填；支持中文俗称 |
| 前 / 后 | 下拉：不限 / 前 / 后 | 默认不限 |
| 宽度 | 数字框 | 可留空；单位 mm |
| 孔数 | 数字框 | 可留空 |
| 查询 | 按钮 | 回车等价 |

### 3.2 候选卡（每卡固定四行，顺序不许变）

1. **规格**：`188×155×12.2/14` ｜ 孔数 10 ｜ 孔距 120 ｜ 片数 8
2. **证据**：`kooying catalog.pdf p27 · 第 1 列第 6 行`
3. **置信度徽章**：高 / 中 / 低 + 一句话原因（如「车型精确，缺前/后」）
4. **待核项**：如「第 3、4 个数字语义待企业确认」，无则显示「—」

卡片底部：勾选框（用于生成草稿）。

### 3.3 底部动作

- `生成报价草稿`（勾选 ≥1 个候选后可用）
- `复制追问话术`（中/英两段，各自一键复制）

### 3.4 未命中态

- 大字：**未收录**
- 副文案：`最相近的车型：xxx / yyy / zzz`（点击可重查）
- 三条追问：如「是前桥还是后桥？」「原车片宽是多少？」「是 A 版还是 B 版？」
- **禁止出现任何型号或尺寸字段**

### 3.5 手机速答模式

`?mode=mobile`：隐藏导航与背景装饰，输入框 + 候选卡上下堆叠，字号放大一档，无横向滚动。

---

## 4. 防幻觉硬规则（写进代码，不是写进文档）

1. **候选只能来自 `fitment.jsonl` 的检索结果。** 没有任何“模型生成候选”的路径。
2. **`assert_unique=true` 只允许一种情况**：置信度=高 且 候选数=1。其余一律 `false`，前端不得显示“就是这一款”。
3. **每条候选必须能指回 `文件 + 页码 + 单元格`。** 指不回去的不许展示。
4. **价格字段恒为空。** 系统里没有价表，任何价格都是编的。
5. **未命中时不许“推测”。** 只给最相近车型名与追问。

---

## 5. 数据能说什么、不能说什么（台上口径）

| 能说 | 不能说 |
| --- | --- |
| 153 条记录来自两本真实产品册的 6 页 | 「全量产品目录」 |
| 145 条同时有车型与尺寸 | 「覆盖所有车型」 |
| 每张候选卡都能点到页码 | 「100% 准确」 |
| 冲突条目自动标「待核」 | 「数据已经清洗完毕」 |
| 车桥只有“桥厂 + 吨位”级别（12 条） | 「能识别车桥型号」 |
| 型号（GYS/GY）印在图里，需企业给 Excel | 「能报型号」 |
| 价格要人工核 | 「精准报价」 |

## 7. 边界

- 输入是**中文俗称**优先；英文车型名不做（本轮无词表）。
- 尺寸单位统一 mm，不做英寸换算。
- 一条候选对应一条适配表记录，不做“多表合并”。
- 不提供历史查询记录页（查询日志只落文件，供 Q&A 讲“种子→扩表”）。
