## 2. 必过红线（任何一条红 = 不许上台）

| 红线 | 检查方式 |
| --- | --- |
| 页面上出现编造的型号或价格 | 全文搜「GYS」「GY」与「¥」「$」 |
| 未命中页出现尺寸数字 | V7 时肉眼检查 |
| 单价非空 | V9 时看草稿 |
| 接口 500 时页面白屏 | 断开 D2 模块或传空 `q` 看错误态 |
| 手机横向滚动 | V11 时用手划 |
