# 线索承接

工作台入口为 `/comment-desk`。应用读取已有评论和询盘，复核和发送回执只写入 `comment_desk_reviews` 与 `comment_desk_replies`。与原工作台共用登录。飞鸽评论同步继续使用「社媒营销」的入口。

## 核价

客户只问价格即可打开「报价工作台」。没有目录命中时也能导出原话交销售查件。提供 T850 系列或已收录的车型别名时，工作台展示目录候选、规格和出处，可输入关键词缩小列表。导出包含全部候选供核对；每行代表一种可能，不能相加计价。目录覆盖试点适配表及 T850 样例。销售核实实际车桥或旧件，内部核算重量、配方、附件成本，再确认正式价格和币种。

关键词筛选会同步到下载结果。整单数量只出现在第一条候选记录。明细文本如 `19032 STD 150` 与 `19032 1+ 100` 分别保留规格和数量。可识别带行号的文本行，缺少的单位留空。核价单同时保留原文供核查遗漏。图片或扫描件仍需人工读取。

## 回复

展位回复优先使用已匹配的展会配置 `EVENT_NAME`、`EVENT_DATE`、`EVENT_VENUE`、`EVENT_BOOTH`。演示里 2026 上海法兰克福汽配展的展位号来自冠英团队资料。询问展位表示有到展可能，销售须另行确认到场和约见。

飞鸽评论使用「复制回复」和「打开原帖」。原询盘使用「打开已有记录」回原线程处理。Facebook 直连可通过 `COMMENT_DESK_FACEBOOK_SEND=1` 启用「一键回复」，需要已授权的主页令牌、指定帖子以及直接同步或 webhook 来源。启用前须关闭原工作台的自动回复队列，并核对原帖是否已经人工回复。发送前展示正文和目的地，发送失败或结果未确认时，到原帖核对再处理。
