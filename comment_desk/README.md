# 线索承接

## 真实 X 平台演示

本地打开 `http://127.0.0.1:8099/comment-desk?panel=x`，目标固定为 @qsl8880 的帖子 2124107958841753962。页面中的“查看指定原帖”可直接用已登录的浏览器查看评论。

1. 在 X 开发者控制台创建或选择自己的应用，启用 OAuth 2.0 用户授权，允许读取和发帖，回调地址精确填写 `http://127.0.0.1:8099/comment-desk/x/callback`。检查近期搜索与发帖 API 的可用权限和余额。
2. 在启动工作台的同一个 PowerShell 会话中设置 `$env:X_CLIENT_ID = '你的 Client ID'`。保密客户端还需要通过本机密钥配置注入 `X_CLIENT_SECRET`。再启动或重启 8099 服务。回到演示页点击授权按钮。OAuth 用户令牌仅在单进程服务内存中保存，服务重启或令牌过期后重新连接。
3. 授权后可预览近期直接回复及拟回复。企业自动回复活动取得 X 批准后，才能在同一服务环境设置 `X_BRAND_AUTOREPLY_APPROVED=1` 并重启。这里使用规则模板。平台规则见 https://help.x.com/en/rules-and-policies/x-automation 。
4. 用参与演示的另一个账号评论“请报价 WVA 19032”查看草稿。外发演示使用“请自动回复：请发目录”或“Please auto-reply: catalog please”。开启轮询后，保持页面打开。每分钟最多发送一条，范围包含近七天内符合条件的既有评论。离开页面停止后续轮询，已经提交的请求可能继续完成。
5. 核对评论下的真实回执链接。对同一互动再次同步不会重新发出。评论者在会话内回复 STOP 后进入退订表。若发送返回不确定结果，先在原帖核对；同步发现作者已回复后可对账。X 近期搜索有时间窗口，搜索范围之外的历史互动不能用此页面验收。

工作台入口为 `/comment-desk`。应用读取已有评论和询盘，在模块自己的表中保存复核、交接资料、历史和发送回执。与原工作台共用登录。飞鸽评论同步继续使用「社媒营销」的入口。

## 线索交接

三个正式入口对应原工作台的「询盘转化」「客户名单」「社媒营销」。询盘读取已入库且未删除的原询盘，客户名单调用原客户接口，社媒读取同一张评论表里的 Facebook 历史、已同步的飞鸽评论与已载入的中文演示评论。点击询盘或客户链接按原记录编号打开。Facebook 历史支持按评论编号进入，飞鸽原帖链接取同步所得来源。补充演示样本与 X 接入单独显示。

「待客户补充」和「已交核价」要求填写负责人及跟进日期。补充查件资料保存后用于重新查目录，询盘原文另外保留。点击「查看交接记录」可核对最近 30 次更新。已转入业务询盘的评论可打开对应记录。按当前来源可查看逾期、待客户补充和已交核价的数量，并按状态下载。销售在原渠道回复后可登记人工回复，回执栏会注明记录来源。

## 核价

询盘转化和社媒营销的记录沿用来源评分及评分状态。线索承接根据原文和补充资料生成处理建议。

客户只问价格即可打开车型速配的报价工作台。已识别的型号和规格随链接带入。数量明确且按套计量时，可在「选候选并带入套数」中确认速配候选，进入对应报价表。多行采购单可按行查件报价。

「待核价资料」保留试点适配表及 T850 样例的目录依据，供人工核对。没有目录命中时也能导出原话交销售查件。有候选时，每行代表一种可能，整单数量不可按候选累加。销售核实实际车桥或旧件，内部核算重量、配方、附件成本，再确认正式价格和币种。

关键词筛选会同步到下载结果。整单数量只出现在第一条候选记录。明细文本如 `19032 STD 150` 与 `19032 1+ 100` 分别保留规格和数量。可识别带行号的文本行，缺少的单位留空。核价单同时保留原文供核查遗漏。图片或扫描件仍需人工读取。

## 回复

展位回复优先使用已匹配的展会配置 `EVENT_NAME`、`EVENT_DATE`、`EVENT_VENUE`、`EVENT_BOOTH`。演示里 2026 上海法兰克福汽配展的展位号来自冠英团队资料。询问展位表示有到展可能，销售须另行确认到场和约见。

飞鸽评论使用「复制回复」和「打开原帖」。原询盘使用「打开已有记录」回原线程处理。Facebook 直连可通过 `COMMENT_DESK_FACEBOOK_SEND=1` 启用「一键回复」，需要已授权的主页令牌、指定帖子以及直接同步或 webhook 来源。启用前须关闭原工作台的自动回复队列，并核对原帖是否已经人工回复。发送前展示正文和目的地，发送失败或结果未确认时，到原帖核对再处理。
